Apresentações cadastradas

Editar textos de qualquer página

Escolha uma seção do site, altere o HTML da seção e clique em Aplicar. Para pequenas alterações, você pode trocar frases pelo recurso abaixo.

Enviar arquivos de mídia

Selecione uma foto, vídeo ou MP3. O painel prepara o arquivo para download e gera seu caminho. Depois coloque o arquivo na pasta do GitHub Desktop.

O GitHub recomenda arquivos de até 50 MB e bloqueia arquivos acima de 100 MB. Vídeos maiores precisam de hospedagem externa, Git LFS com configuração apropriada ou outra solução.

Substituir foto, vídeo ou música no HTML

Para adicionar um novo card de vídeo ou uma galeria, use a seção Vídeos em “Textos e páginas” ou o Editor avançado.

Editor completo do site

Permite editar qualquer elemento do site, inclusive menus, layout, vídeos, formulários, estilos e scripts. Faça alterações com cuidado.

Salvar alterações

Baixe o novo index.html e coloque-o na pasta Documentos/GitHub/site-lippi-e-leo, substituindo o arquivo antigo somente após fazer uma cópia de segurança.

Para publicar: no GitHub Desktop, confira os arquivos alterados, escreva uma mensagem no campo Summary, clique em Commit to main e depois em Push origin. Aguarde o GitHub Pages atualizar. Fotos e vídeos novos também precisam estar na pasta do repositório.
